# AI Inventory Optimization — Interactive Research Lab

Forecast-accuracy vs inventory-cost study (M5 + Store Item Demand, 500 series each,
8 rolling origins × 28-day horizon) with a Streamlit laboratory for interrogating
the published evidence.

**Locked thesis:** LSTM wins forecast accuracy on both datasets (M5 MASE 1.316,
Store MASE 0.978), but Moving Average wins Store inventory cost (2084.50 vs LSTM
2247.46) under the common policy (L7 / 95% / H=1 / P=5).

## Streamlit entrypoint

```
app/streamlit_app.py
```

4 pages (`app/views/`, driven by `st.navigation` — the directory is deliberately
named `views/`, not `pages/`, so Streamlit does not auto-inject a second nav):

| # | Page | Mode |
|---|------|------|
| 01 | Frozen Results | Locked / published evidence (read-only) |
| 02 | Forecast Explorer | Interactive, cached sample traces |
| 03 | Inventory Lab | Interactive, 27-policy sensitivity grid |
| 04 | Methodology | Frozen protocol |

## Run locally (from a clean clone)

Requirements: Python 3.10+ (verified on 3.12).

```bash
git clone https://github.com/srivatsacool/ai-inventory-optimization.git
cd ai-inventory-optimization
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

Verify the evidence lock on first run — page 01 aborts with an error if any of
the 7 thesis rows in `09_reports/final/data/final_number_sheet.csv` mismatch, or
from a shell:

```bash
python -c "import sys; sys.path.insert(0,'.'); from app.lib.frozen_loader import thesis_ok; print(thesis_ok())"
# True
```

Regenerate the interactive extracts (optional — `app_data/` is committed):

```bash
python scripts/build_app_data.py
```

## Deploy to Streamlit Community Cloud

1. Push this repo to GitHub (branch `main`).
2. Go to https://share.streamlit.io → **New app** → select repo
   `srivatsacool/ai-inventory-optimization`, branch `main`.
3. **Main file path:** `app/streamlit_app.py`
4. Requirements are picked up automatically from `/requirements.txt`
   (pinned: `streamlit`, `pandas`, `plotly`, `numpy` — nothing else).
5. No secrets or env vars required. Any Python Cloud offers (3.12 or 3.14):
   all pins ship wheels for both, and `streamlit==1.43.2` caps pandas to <3.
6. Click **Deploy**. Page 01 self-verifies the evidence freeze on every load.

## Data contract (do not break)

- **Frozen evidence (amber):** read-only via `app/lib/frozen_loader.py` from 9 files
  tracked at tag `v1.0-evidence-freeze` (`06_results/inventory/…`,
  `07_figures/inventory/…`, `09_reports/final/…`, `docs/research/experiment-protocol.md`).
  Never recompute or reinterpret here. These live under otherwise-ignored dirs
  and are kept tracked by exception — see `.gitignore`.
- **Interactive / derived (blue):** small extracts in `app_data/` (tracked, < 2 MB),
  read via `app/lib/appdata_loader.py`, always labeled in the UI. Generated by
  `scripts/build_app_data.py`.
- `app/lib/lab.py` renders only — it never computes research values.

## Static site (Cloudflare Pages, separate deployment)

`site/` is an Astro static site. `/lab` embeds the independently hosted Streamlit
app via the `ASTRO_STREAMLIT_URL` env var (see `site/src/config.mjs`); with no URL
set it shows a graceful fallback. The Streamlit app is never converted to static
output. Deploy the site to Cloudflare Pages with build command `npm run build`
(`prebuild` stages the canonical PDF from `09_reports/final/report.pdf`).
