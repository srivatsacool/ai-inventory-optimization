# app_data - DERIVED, not evidence

Small tracked extracts for the interactive lab only. Generated by
scripts/build_app_data.py on branch app/streamlit-v1. Never cite these in
place of the frozen results (09_reports/final/data/final_number_sheet.csv,
06_results/inventory/*.csv at tag v1.0-evidence-freeze).

Contents:

- datasets.csv: 2 rows, dataset metadata for selectors.
- models.csv: model ladder metadata (family, applicability).
- representative_series.csv: origin-1 H28 actuals for 4 sample series.
- forecasts_sample.csv: cached forecasts for those series across families.
- sensitivity_compact.csv: copy of the 27-policy grid (540 rows), the only
  full-size file here because the grid itself is already small.

Size budget: total under 2 MB. Do not add raw catalogs or full forecast
tensors here.
